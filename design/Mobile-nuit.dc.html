Partie 8, section c

Cacher les rôles avec un interceptor

Projet : Loup-Garou Environ 45 minutes

Pour l'instant, n'importe quel joueur peut appeler GET /villages/:id et lire le rôle de tout le monde. La partie est gâchée avant d'avoir commencé.

Un interceptor s'exécute sur toutes les réponses d'une route : c'est l'endroit idéal pour cacher ce que le joueur n'a pas le droit de voir.
