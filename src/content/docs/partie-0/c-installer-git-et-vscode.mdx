Deux outils que tu vas utiliser à chaque partie du cours.

## Git

**Git** garde l'historique de ton code : chaque **commit** est une photo de ton projet à un instant donné, que tu peux toujours retrouver. Installe-le depuis [git-scm.com](https://git-scm.com), puis vérifie :

```bash
git --version
```

Git a besoin de savoir qui tu es, pour signer tes commits :

```bash
git config --global user.name "Ton nom"
git config --global user.email "ton@email.com"
```

## VS Code

**VS Code** est un éditeur de code gratuit, avec un terminal intégré et une bonne prise en charge de TypeScript — ce qui compte pour ce cours. Installe-le depuis [code.visualstudio.com](https://code.visualstudio.com/).
