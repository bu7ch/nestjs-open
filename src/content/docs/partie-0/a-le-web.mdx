Quand tu tapes une adresse dans ton navigateur, celui-ci envoie une **requête HTTP** à un serveur. Le serveur répond avec une **réponse HTTP**. Tout le cours repose sur cet échange.

```http
GET /api/villages HTTP/1.1
Host: localhost:3000
Accept: application/json
```
