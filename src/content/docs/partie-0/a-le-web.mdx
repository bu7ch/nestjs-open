Quand tu tapes une adresse dans ton navigateur, celui-ci envoie une **requête HTTP** à un serveur. Le serveur répond avec une **réponse HTTP**. Tout le cours repose sur cet échange.

```http
GET /api/villages HTTP/1.1
Host: localhost:3000
Accept: application/json
```

Le serveur répond avec un code de statut (`200` : tout va bien) et, ici, du **JSON**. Côté serveur, avec NestJS, la méthode qui produit cette réponse ressemblera à ça. Les deux lignes surlignées font le travail : on lit le village demandé, puis on le renvoie.

```ts title="src/villages/villages.controller.ts" {6,7}
import { Controller, Get, Param } from '@nestjs/common';

@Controller('api/villages')
export class VillagesController {
  @Get(':id')
  trouverUn(@Param('id') id: string) {
    return { id, phase: 'nuit', tour: 3 }; // NestJS le transforme en JSON
  }
}
```

Pas de panique : tu écriras ton premier controller en partie 3. Retiens juste l'échange requête puis réponse.
