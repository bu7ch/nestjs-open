Comment un navigateur et un serveur se parlent : HTTP, requêtes, réponses, JSON. On installe aussi les outils : terminal, Git, VS Code, Node.js.

Cette partie ne demande aucun prérequis technique, juste les bases de la programmation (variables, conditions, boucles, fonctions). À la fin, ton ordinateur sera prêt pour écrire du code NestJS, et tu auras compris l'échange requête/réponse qui traverse tout le cours.

## Ce que tu vas faire

- **a.** Comprendre comment un client et un serveur communiquent en HTTP.
- **b.** Te déplacer et créer des dossiers depuis le terminal.
- **c.** Installer Git (l'historique de ton code) et VS Code (ton éditeur).
- **d.** Installer Node.js et exécuter ton premier script.
