Jusqu'ici, tu as sans doute utilisé ton ordinateur avec la souris : des fenêtres, des dossiers, des doubles clics. Le **terminal** fait la même chose en tapant des commandes. C'est plus lent au début, mais c'est l'outil que tout développeur backend utilise : lancer un serveur, installer une librairie ou déployer, tout ça passe par le terminal.

Ouvre un terminal (l'app Terminal sur macOS, ou l'invite de commandes / WSL sur Windows). Il affiche une **invite** (prompt), avec le dossier où tu te trouves.

```bash
pwd
```

`pwd` (*print working directory*) affiche le dossier courant. Pour voir ce qu'il contient :

```bash
ls
```

Pour se déplacer dans un dossier :

```bash
cd nom-du-dossier
```

Et pour remonter d'un niveau :

```bash
cd ..
```

Enfin, pour créer un dossier :

```bash
mkdir mon-dossier
```

Ces cinq commandes suffisent pour l'instant. Tu en apprendras d'autres au fil du cours, en les utilisant.
