**Node.js** exécute du JavaScript en dehors d'un navigateur — c'est lui qui fera tourner ton serveur NestJS. Installe la version **LTS** (*Long Term Support*, la plus stable) depuis [nodejs.org](https://nodejs.org/), puis vérifie :

```bash
node --version
npm --version
```

`npm` (*Node Package Manager*) est installé avec Node. Il télécharge les librairies dont ton projet a besoin — NestJS en fait partie.

Node exécute un fichier `.js` directement :

```bash
node mon-script.js
```
