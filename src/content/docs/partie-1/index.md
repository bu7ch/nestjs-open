Le JavaScript moderne utile au backend, l'asynchrone (promesses, async/await), puis TypeScript : types, classes, interfaces et décorateurs.

NestJS est écrit en TypeScript et s'appuie beaucoup sur les classes et les décorateurs. Cette partie te donne juste ce qu'il faut pour être à l'aise avec cette syntaxe avant d'écrire ton premier controller, en partie 3.

## Ce que tu vas faire

- **a.** Le JavaScript moderne utile au backend : `const`/`let`, fonctions fléchées, déstructuration, modules.
- **b.** L'asynchrone : callbacks, promesses, `async`/`await`.
- **c.** TypeScript, les bases : installer le compilateur, types, interfaces.
- **d.** TypeScript, classes et décorateurs.
