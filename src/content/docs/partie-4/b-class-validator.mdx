**class-validator** ajoute des règles à un DTO, sous forme de décorateurs — encore une fois, le même principe qu'en partie 1. **class-transformer** l'accompagne : il transforme le JSON brut reçu en véritable instance de ta classe, pour que les décorateurs aient quelque chose à inspecter.

```bash
npm install class-validator class-transformer
```

```ts title="src/villages/dto/creer-village.dto.ts" {1,4,5,8,9}
import { IsArray, IsInt, IsString, Min } from 'class-validator';

export class CreerVillageDto {
	@IsInt()
	@Min(3)
	nombreDeJoueurs: number;

	@IsArray()
	@IsString({ each: true })
	rolesEnJeu: string[];
}
```

Ces décorateurs seuls ne suffisent pas : il faut dire à NestJS de les faire respecter. C'est le rôle de `ValidationPipe`, à activer une fois pour toute l'application :

```ts title="src/main.ts" {2,6}
import { NestFactory } from '@nestjs/core';
import { ValidationPipe } from '@nestjs/common';
import { AppModule } from './app.module.js';

async function bootstrap() {
	const app = await NestFactory.create(AppModule);
	app.useGlobalPipes(new ValidationPipe());
	await app.listen(process.env.PORT ?? 3000);
}
await bootstrap();
```

À partir de là, un village créé avec `nombreDeJoueurs: 1` reçoit un `400`, avec le détail de chaque règle violée :

```json
{
	"message": ["nombreDeJoueurs must not be less than 3"],
	"error": "Bad Request",
	"statusCode": 400
}
```

## Champs optionnels, champs superflus

`@IsOptional()` dispense un champ des autres décorateurs quand il est absent — mais continue de les appliquer s'il est présent. `whitelist: true`, dans les options de `ValidationPipe`, retire silencieusement les champs qui n'ont aucun décorateur dans le DTO ; `forbidNonWhitelisted: true` les rejette carrément au lieu de les ignorer :

```ts
app.useGlobalPipes(new ValidationPipe({ whitelist: true, forbidNonWhitelisted: true }));
```

Sans ça, un client pourrait glisser un champ que ton DTO n'attend pas — sans que rien ne le signale.

<Exercice numero="4.5" titre="Un champ optionnel">

<Exercice numero="4.6" titre="Refuser les champs en trop">
